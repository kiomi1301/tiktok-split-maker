# Changelog

## 1.0.0

First public release.

- English interface by default
- Russian interface preserved and available from the top-bar language switch
- Active US/RU flag indicator
- Single and Multi modes
- Batch cutting with configurable clip duration
- Continuous looping bottom-video timeline across batch clips
- NVIDIA NVENC / CPU x264 encoding
- Live preview, drag & drop, ETA, render speed and progress
- Fully autonomous Windows build with bundled FFmpeg and ffprobe
- About dialog with project authorship and license information
- GNU GPL v3.0 project license
- Reproducible GitHub Actions release build with pinned FFmpeg checksum
- No UPX or code obfuscation in release builds
