# TikTok Split Maker

Быстрая Windows-программа для объединения основного видео с gameplay / satisfying видео снизу в вертикальные ролики **1080×1920**.

**Автор:** [kiomi](https://github.com/kiomi1301)  
**В сотрудничестве с:** ChatGPT, OpenAI  
**Лицензия:** GNU GPL v3.0

> По умолчанию интерфейс английский. Русский включается мгновенно кнопкой с флагом в верхней панели.

## Возможности

- Тёмный современный интерфейс
- Мгновенное переключение English / Русский
- Drag & Drop видео
- Предпросмотр компоновки
- Одиночный режим
- Мульти-режим с автоматической нарезкой
- 70/30, 65/35 и 60/40
- NVIDIA NVENC (`h264_nvenc`) при наличии
- CPU x264 как запасной вариант
- High / Very high / Small file
- Непрерывный таймлайн нижнего видео в мульти-режиме
- Автоматический цикл нижнего видео после его окончания
- Общий прогресс, прогресс текущего ролика, ETA и скорость рендера
- Корректная отмена очереди: готовые ролики остаются, недоделанный удаляется
- Полностью автономный Windows-релиз: пользователю не нужны Python, FFmpeg или настройка PATH

## Мульти-режим

Если основное видео длится 25 минут, а длина одного ролика выставлена на 65 секунд, программа сама создаёт:

```text
source_001.mp4
source_002.mp4
source_003.mp4
...
```

Основное видео режется последовательно, без пропусков и повторов. Нижнее видео идёт по своей общей временной линии. Если оно заканчивается внутри очередного ролика, программа берёт остаток с конца и продолжает с начала.

Например:

```text
20 сек с конца нижнего видео
+
45 сек с начала
=
цельный ролик 65 сек
```

Последний неполный кусок основного видео не выбрасывается.

## Сборка из исходников

Для разработчика нужны:

- Windows 10/11 x64
- Python 3.12 x64
- интернет для скачивания закреплённой сборки FFmpeg

Запусти:

```bat
build_release.bat
```

Скрипт скачает и проверит FFmpeg, установит зависимости, запустит тесты и создаст:

```text
dist\TikTok Split Maker.exe
```

Используется PyInstaller `--onefile --noupx`, без обфускации и сторонних упаковщиков.

## Антивирусы / SmartScreen

Неподписанные one-file программы PyInstaller иногда получают ложные эвристические срабатывания. В проекте специально не используются обфускация и UPX. Исходники и процесс сборки открыты, поэтому релиз можно проверить и воспроизвести.
